## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/SumitKumargiri/projects.git
cd projects
```

### Install Dependencies

Navigate to a specific project folder and install dependencies:

```bash
cd project-1
npm install
```

### Run Project

```bash
npm run dev
```

or

```bash
npm start
```
